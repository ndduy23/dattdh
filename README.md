This is a simple 2D platformer game developed using Unity. The player controls a character who can run, jump, and navigate through a side-scrolling level filled with platforms, obstacles, and collectibles.
The goal is to reach the end of each stage while avoiding hazards and enemies.

The game features smooth character movement, collision detection, and basic physics using Unity’s built-in 2D tools. Levels are designed with tile-based platforms, background layers for depth, and interactive objects such as coins or keys. 
All sprites, animations, and tilemaps are taken from Unity’s free 2D Game Kit and default asset packages, ensuring quick prototyping without custom art creation.


Core functionalities include:

  - Player movement (run, jump, and fall).

  - Collision handling with platforms and objects.

  - Basic enemy AI (patrolling, damaging the player on contact).

  - Collectible items that increase score.

  - Level completion triggers.

This project demonstrates fundamental 2D game development concepts in Unity, including sprite animation, Rigidbody2D physics, and C# scripting. It serves as a beginner-friendly foundation for creating more advanced platformer games.
